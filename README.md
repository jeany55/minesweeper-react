# Minesweeper

A modern take on the classic Minesweeper game, built with React and Material UI.

**[Play it here](https://jeany55.github.io/minesweeper-react/)**

## Features

- Customizable grid size (5-30 rows/columns) and mine count
- Quick presets: Easy (9x9), Medium (16x16), Hard (16x30)
- Real-time timer and flag counter
- Session stats with win rate and best time tracking
- Responsive design with dynamic tile sizing
- Mobile/tablet support with tap-to-dig and long-press-to-flag
- Glass-morphism UI with animated backgrounds

## How to Play

| Platform | Dig | Flag |
|----------|-----|------|
| Desktop | Left click | Right click |
| Mobile/Tablet | Tap | Long press |

On mobile, use the **dig lock** switch to prevent accidental digs while flagging.

## Getting Started

```bash
npm install
npm run dev
```
